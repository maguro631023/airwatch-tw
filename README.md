# 此刻空氣 — GPS × 空污 × 溫濕度 即時警報

以手機 GPS 定位，即時比對最近的**環境部空品測站**與**中央氣象署自動氣象站**，
計算 AQI 等級與熱指數體感溫度，超過個人門檻時發出警報。單頁 PWA，可加到手機主畫面。

## 〇、QR Code 與預設金鑰

設定頁最下方有 QR Code 區塊，兩種模式：

- **只有網址** — 掃描後開啟本站，適合分享給別人或從電腦傳到手機。
- **含金鑰與設定** — 把 API 金鑰與所有門檻編進網址 hash，新裝置掃完直接就緒，
  不必手動貼金鑰。**這張圖等於你的金鑰，不要公開分享。**

掃描帶入後，網址列會立刻被清乾淨（`history.replaceState`），金鑰不會留在網址列。
QR 產生器是內建的（byte mode、版本 1–10、EC 等級 M/L），不依賴任何 CDN，離線也能產。

金鑰已預先填入程式碼，安裝後即可使用；設定頁有「重設為預設金鑰」按鈕。
**注意：public repo 的前端等於公開這兩把金鑰**，任何人都能從原始碼讀到。
兩把都是免費唯讀的政府開放資料金鑰，外洩不涉及個資，但配額可能被他人用掉。
若要給多人使用，請改用 Cloudflare Worker 代理把金鑰移到後端。

## 二、部署到 GitHub Pages

```bash
git init && git add . && git commit -m "init"
git branch -M main
git remote add origin https://github.com/maguro631023/airwatch-tw.git
git push -u origin main
# Settings → Pages → Source: main / (root)
```

網址會是 `https://maguro631023.github.io/airwatch-tw/`。
**必須用 HTTPS**，Geolocation 與 Notification 在 http 下會被瀏覽器擋掉（localhost 除外）。

手機開啟後：Safari 分享選單「加入主畫面」，或 Chrome 選單「安裝應用程式」。

## 三、系統怎麼運作

```
watchPosition ──> 座標
                   ├─> aqx_p_432 全站資料 ──> Haversine 最短距離 ──> 最近空品站
                   └─> O-A0003-001 全站資料 ─> Haversine 最短距離 ──> 最近氣象站
                                                         │
                          AQI 分級 ────┐                  │
                          PM2.5 濃度 ──┼──> 警報判定 ──> 橫幅 / 系統通知 / 震動
                          熱指數 HI ───┤
                          相對濕度 ────┘
                                        └──> 暴露紀錄（localStorage，可匯 CSV）
```

幾個刻意的設計決定：

- **兩個資料源各自找最近站，不共用測站。** 空品站全台約 80 站、氣象站數百站，
  硬把溫濕度綁在空品站的位置上只會犧牲精度。
- **移動超過 1.5 公里才重新抓資料。** `watchPosition` 會頻繁回報，逐次呼叫 API
  既耗電也無意義（空品資料本來就每小時才更新一次）。
- **警報有遲滯設計。** 只在等級「上升」或同級別持續超過 30 分鐘時才重複通知，
  避免數值在門檻上下擺盪時連環轟炸。
- **敏感族群會下修一級。** 選擇呼吸道疾病、心血管疾病、長者、兒童、孕期時，
  AQI 判定等級 +1，建議文字也切換成對應版本。
- **熱指數採 Rothfusz 迴歸式**（NWS 標準），由氣溫與相對濕度推算體感。
  33°C / 75% RH 會算出約 45.7°C 體感，落在「危險」區間——這是台灣夏天的日常，
  也正是單看氣溫會漏掉的風險。
- **Service Worker 不快取 API 回應**，只快取應用外殼。空品數值過期比沒有數值更危險。

## 四、已知限制

1. **網頁通知只在頁面存活時發出。** iOS Safari 尤其嚴格，App 切到背景一段時間後
   計時器會被凍結。要做到真正的離線推播，需要一台伺服器發 Web Push，
   或改寫成原生 / Capacitor 包裝。
2. **金鑰寫在前端。** 對個人工具可接受（兩把都是免費唯讀金鑰），
   但若要公開給多人使用，應改為 Cloudflare Worker 之類的代理端點，把金鑰藏在後端，
   順便做快取以降低對政府平台的請求量。
3. **CORS 若被擋**，同樣以上述代理解決。
4. 測站是點位觀測，離你最近不等於代表你的實際暴露；室內、車內、地下空間差異都很大。

## 五、可以往哪裡長

- 暴露紀錄已含時間、座標、AQI、PM2.5、溫濕度，直接可算**個人累積暴露劑量**
  （∑ 濃度 × 停留時數），是個人暴露評估研究的現成資料格式。
- 加入運動/通勤模式：偵測移動速度，行進中自動提高採樣頻率並標記路徑。
- 多測站空間內插（IDW 或 kriging）取代「取最近站」，可明顯改善都會區邊緣的估計。
- 若要做族群層級的決策支援，AQI、PM2.5、體感溫度、族群脆弱度可以直接接成一組
  多準則評估，用來排序「今天哪些行政區該發布戶外活動限制」。
